# El Pollo Loco

A jump-and-run browser game with custom game logic, animations, and enemies — built with vanilla JavaScript and object-oriented programming.

**Live Demo:** [elpolloloco.bilal-acil.de](https://elpolloloco.bilal-acil.de)

## Features

- Smooth character movement and animations
- Enemy AI with collision detection
- Game loop with win/lose conditions

## Architecture

Clear class structure with separated responsibilities for player, enemies, and environment. Developed step-by-step from core mechanics to a complete game experience.

## What I learned

- OOP in practice: inheritance, encapsulation, and reusable classes
- Implementing a game loop and frame-based animation
- Collision detection and animation state management
